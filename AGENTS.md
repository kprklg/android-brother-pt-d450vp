# Правила работы над проектом (промпт)

Этот файл — обязательные правила для всех сессий и участников. OpenCode читает `AGENTS.md` автоматически.

## 1. Документация на все шаги
Любое изменение в проекте сопровождается документацией в Git:
- `README.md` — общее описание, возможности, быстрый старт;
- `docs/NN-*.md` — пошаговые документы (среда, протокол, архитектура, git-crypt/релизы, тестирование);
- `CHANGELOG.md` — что изменилось в каждом релизе;
- `TASKS.md` — дорожная карта и список задач.

## 2. Чувствительные данные — только через `git-crypt`
Обязательное шифрование (`git-crypt`) для:
- `group_vars/all/secrets.yml` — токены, пароли, параметры подписи APK;
- `session/*.json` — выгрузки сессий OpenCode;
- `*.secret`, `*.key` — прочие секреты.

Правила зафиксированы в `.gitattributes`. Перед каждым `git push` обязательно:
```bash
git-crypt status -e
```
В выводе `group_vars/all/secrets.yml` и `session/*.json` должны быть помечены как `encrypted`.

Симметричный ключ `git-crypt` хранится **вне репозитория**:
```text
/home/android-brother-pt-d450vp/.keys/android-brother-pt-d450vp.git-crypt.key
```
Ключ нельзя коммитить, копировать в репозиторий или публиковать. Резервная копия — в менеджере паролей владельца.

## 3. Релизы и теги — всегда
Каждый значимый этап (включая изменения только в документации):
1. обновить `CHANGELOG.md`, `TASKS.md` и `docs/`;
2. собрать и прогнать тесты: `./scripts/build-and-test.sh`;
3. закоммитить, поставить аннотированный тег `vX.Y.Z`;
4. запушить `main` и тег;
5. создать GitHub Release (`gh release create`), для кода — с APK.

Версионирование — [Semantic Versioning](https://semver.org/): `MAJOR.MINOR.PATCH`.

## 4. Идемпотентность
Все скрипты и команды должны быть идемпотентными: повторный запуск не ломает состояние и даёт тот же результат. Используйте `mkdir -p`, проверки существования, `--force`/`-r` только осознанно.

## 5. Выгрузка сессий OpenCode
Перед релизом/завершением этапа — выгрузить сессию в `session/<SESSION_ID>.json` и зашифровать `git-crypt`:
```bash
./scripts/export-session.sh
```
Скрипт сам проверяет правило шифрования и путь к `opencode`. Выгрузка без шифрования запрещена.

## 6. Git-гигиена
- Рабочая ветка — `main`, удалённый репозиторий: `https://github.com/kprklg/android-brother-pt-d450vp`.
- Токен доступа не хранится в `.git/config` и не попадает в открытые файлы.
- Перед коммитом проверять `git status` и отсутствие секретов в диффе.
