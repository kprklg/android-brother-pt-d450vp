# Шаг 2. Протокол Brother PT-D450VP и данные с реального принтера

## Почему прямой USB Host API вместо Brother Print SDK

Модель **Brother PT-D450 / PT-D450VP** ориентирована на USB-подключение и не входит в стандартный список поддерживаемых моделей официального Brother Print SDK для Android. При этом принтер полностью поддерживает документированный растровый протокол **Brother P-touch Raster** поверх стандартного USB Printer Class.

## Фактические USB-параметры реального принтера

Снято 27.11.2026 через `lsusb -v -d 04f9:2073`:

| Параметр | Значение |
|---|---|
| `idVendor` | `0x04f9` (`1273`, Brother Industries, Ltd) |
| `idProduct` | `0x2073` (`8307`, PT-D450) |
| `iManufacturer` / `iProduct` | `Brother` / `PT-D450` |
| `bInterfaceClass` | `7` (`USB_CLASS_PRINTER`) |
| `bInterfaceSubClass` | `1` (Printer) |
| `bInterfaceProtocol` | `2` (Bidirectional) |
| Bulk OUT endpoint | `0x02` (`EP 2 OUT`, `wMaxPacketSize = 64`) |
| Bulk IN endpoint | `0x81` (`EP 1 IN`, `wMaxPacketSize = 64`) |

В Android-приложении фильтр описан в `app/src/main/res/xml/device_filter.xml`.

## Фактический 32-байтный ответ статуса (`ESC i S`)

Запрос: 100 нулевых байт (`0x00`) + `1B 40` (`ESC @`) + `1B 69 53` (`ESC i S`).

Реальный ответ подключённого PT-D450VP:
```text
80 20 42 30 69 30 00 00 00 00 0C 01 00 00 00 00
00 00 00 00 00 00 00 00 01 08 00 00 00 00 00 00
```

Расшифровка ключевых байтов (реализовано в `PrinterStatus.kt`):
- `byte[0..1] = 80 20`: заголовок и длина (32 байта).
- `byte[4] = 0x69`: код модели **PT-D450 / PT-D450VP**.
- `byte[8..9] = 00 00`: ошибок нет (`error1`, `error2`).
- `byte[10] = 0x0C` (`12`): ширина ленты **12 мм**.
- `byte[11] = 0x01`: тип носителя — **ламинированная лента TZe**.
- `byte[18] = 0x00`: ответ на запрос статуса.
- `byte[24] = 0x01`: цвет ленты — **белая**.
- `byte[25] = 0x08`: цвет текста — **чёрный**.

## Геометрия термоголовки PT-D450VP

- Разрешение: **180 dpi** (~7.087 точек/мм).
- Ширина термоголовки: **128 пинов** (**16 байт** на одну растровую строку).
- Печатная область центрируется внутри 128 пинов (`marginPins = (128 - printablePixels) / 2`):

| Ширина ленты TZe | `mediaWidthByte` | Печатная высота (px) |
|---|---:|---:|
| 3.5 мм | `4` | 24 |
| 6 мм | `6` | 32 |
| 9 мм | `9` | 50 |
| 12 мм | `12` | 70 |
| 18 мм | `18` | 112 |

## Последовательность команд печати (`RasterProtocol.kt`)

1. `0x00` × 100 — сброс буфера.
2. `1B 40` (`ESC @`) — инициализация.
3. `1B 69 61 01` (`ESC i a 0x01`) — переход в режим Raster.
4. `1B 69 7A <flags> <mediaType> <mediaWidth> 00 <lines LE32> <pageFlag> 00` (`ESC i z`) — информация о печати.
5. `1B 69 4D 00` (`ESC i M`) — базовый режим (у PT-D450 ручной резак).
6. `1B 69 4B <0x08 | 0x00>` (`ESC i K`) — расширенный режим (`0x08` = обычная подача, `0x00` = Chain Print).
7. `1B 69 64 <lo> <hi>` (`ESC i d`) — поле подачи в точках.
8. `4D <0x02 | 0x00>` (`M`) — сжатие (`0x02` = TIFF PackBits, `0x00` = без сжатия).
9. Для каждой растровой строки:
   - пустая строка: `5A` (`Z`);
   - непустая строка: `47 <lenLo> <lenHi> <payload>` (`G`).
10. Конец страницы: `0C` (если следуют ещё копии) или `1A` (последняя копия, печать с подачей).
