# Шаг 5. Тестирование и калибровка печати на реальном PT-D450VP

## 1. Автоматические юнит-тесты (JVM, без принтера)

Запускаются командой `./scripts/build-and-test.sh` (или `./gradlew testDebugUnitTest`):

- `PackBitsEncoderTest` — проверка сжатия/распаковки TIFF PackBits (пустые, сплошные, чередующиеся и смешанные растровые строки).
- `PrinterStatusTest` — проверка парсинга 32-байтного пакета статуса, включая **реальный дамп, снятый с PT-D450VP (`modelCode = 0x69`, 12 мм белая TZe)**, и расшифровку флагов ошибок.
- `RasterProtocolTest` — проверка последовательности команд `ESC @`, `ESC i a`, `ESC i z`, `ESC i M/K/d`, `M 0x02`, центрирования на 128 пинах и терминаторов `0x0C`/`0x1A`.
- `BarcodeGeneratorTest` — генерация UTF-8 QR, Code 128, валидация EAN-13, Data Matrix.
- `DitheringTest` — пороговая бинаризация, инверсия и баланс точек Флойда–Стейнберга.

## 2. Проверка статуса реального принтера на Linux (без расхода ленты)

```bash
python3 scripts/probe-printer.py
```

Скрипт открывает `/dev/usb/lp0`, сбрасывает буфер, отправляет `ESC @` + `ESC i S` и выводит расшифровку 32-байтного ответа (модель, ширина/тип/цвет кассеты, ошибки).

## 3. Калибровка печати на реальной ленте (выполнено 27.11.2026, `v0.1.4`)

Первая печать выполнена с ПК через `scripts/test-print.py` на ленте **12 мм белая TZe** (PT-D450VP, `/dev/usb/lp0`).

### Результат калибровки
1. **Ориентация (`mirrorVertical`):** первый тест с `mirrorVertical = true` дал вертикально перевёрнутый текст (буквы «вверх ногами», порядок слева направо сохранён). После отключения отражения текст и стрелка ↑ читаются правильно. **Зафиксировано значение по умолчанию `false`.**
2. **Сжатие (`useCompression`):** `M 0x02` (TIFF PackBits) отработало без артефактов и пропусков на тексте, стрелке и рамке.
3. **Центрирование:** рамка печатается по всей печатной области 70 px, симметрично относительно 128-пиновой головки — подстройка не требуется.
4. **Поле подачи (`feedMarginDots`):** `14` точек (≈2 мм) достаточно для ручного резака; менять не потребовалось.
5. **Статус после печати:** принтер вернул пакет с `statusType = 0x06` (смена фазы) и `error1 = error2 = 0` — задание принято без ошибок.

### Команда для повторной калибровки
```bash
python3 scripts/test-print.py                  # правильная ориентация (без зеркала)
python3 scripts/test-print.py --mirror         # legacy-режим с вертикальным отражением
python3 scripts/test-print.py --dry-run        # только собрать пакет, без печати
```

### Экономия ленты
- **Пустой лидер перед первой этикеткой (~25 мм)** — физическое расстояние от печатной головки до ножа; он отрезается вместе с этикеткой и не программируется.
- **`ESC i d`** задаёт верхнее и нижнее поле (14 точек ≈ 2 мм с каждой стороны) — защищает край от ножа.
- **Chain Print включён по умолчанию:** промежуточные страницы завершаются `0x0C` (печать без выброса), поэтому между копиями нет лидера; выброс (`0x1A`) выполняется только после последней копии. Это основной способ экономии при серийной печати.
- **Диалог отреза (`v0.1.5`):** после успешной печати приложение показывает «Нажмите на нож, чтобы отрезать ленту» — один диалог на партию. При Chain Print в нём есть подсказка разрезать ленту между этикетками.

6. **USB OTG на смартфоне (проверено автором, `v0.2.0`):** APK установлен на Android-смартфон, печать с PT-D450VP через OTG работает. Детальные протоколы осмотра/status-пакетов можно добавить здесь при повторной калибровке.
7. **Проекты (`v0.2.0`):** проверен диалог сохранения/открытия проекта и экспорт JSON на эмуляторе Android 15; скриншот — `docs/screenshots/06-projects.png`. Юнит-тесты `ProjectCodecTest` покрывают round-trip документа с текстом, QR и картинкой, отказ неподдерживаемой версии и формирование безопасного имени файла.
