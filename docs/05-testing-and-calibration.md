# Шаг 5. Тестирование и калибровка печати на реальном PT-D450VP

## 1. Автоматические юнит-тесты (JVM, без принтера)

Запускаются командой `./scripts/build-and-test.sh` (или `./gradlew testDebugUnitTest`):

- `PackBitsEncoderTest` — проверка сжатия/распаковки TIFF PackBits (пустые, сплошные, чередующиеся и смешанные растровые строки).
- `PrinterStatusTest` — проверка парсинга 32-байтного пакета статуса, включая **реальный дамп, снятый с PT-D450VP (`modelCode = 0x69`, 12 мм белая TZe)**, и расшифровку флагов ошибок.
- `RasterProtocolTest` — проверка последовательности команд `ESC @`, `ESC i a`, `ESC i z`, `ESC i M/K/d`, `M 0x02`, центрирования на 128 пинах и терминаторов `0x0C`/`0x1A`.
- `BarcodeGeneratorTest` — генерация UTF-8 QR, Code 128, валидация EAN-13, Data Matrix.
- `DitheringTest` — пороговая бинаризация, инверсия и баланс точек Флойда–Стейнберга.

## 2. Проверка статуса реального принтера на Linux (без расхода ленты)

```bash
python3 scripts/probe-printer.py
```

Скрипт открывает `/dev/usb/lp0`, сбрасывает буфер, отправляет `ESC @` + `ESC i S` и выводит расшифровку 32-байтного ответа (модель, ширина/тип/цвет кассеты, ошибки).

## 3. Калибровка печати на реальной ленте (следующий этап — `v0.2.0`)

На первой короткой тестовой печати (~2–3 см на ленте 12 мм) проверяем:
1. **Ориентация (`mirrorVertical`):** по умолчанию `true` (стандарт термоголовки Brother P-touch). Если текст выйдет вверх ногами — переключить в диалоге **Принтер / USB** и зафиксировать новое значение по умолчанию в `PrintOptions`.
2. **Сжатие (`useCompression`):** по умолчанию `true` (`M 0x02` TIFF PackBits). Проверить отсутствие артефактов на тексте и QR-коде.
3. **Центрирование:** проверить, что верхнее и нижнее поля на 12 мм ленте симметричны (`printablePixels = 70` в 128-пиновой головке).
4. **Поле подачи (`feedMarginDots`):** подобрать минимально комфортный отступ до ножа ручного резака (по умолчанию `14` точек ≈ 2 мм).
5. **USB OTG на смартфоне:** установить `app-debug.apk`, подключить PT-D450VP через OTG-переходник, выдать разрешение USB, запросить статус и распечатать контрольную этикетку.
