# Дорожная карта и список задач (TASKS)

## Выполнено (`v0.1.0`)

- [x] Установлена и настроена среда Android-разработки на Ubuntu (`Android Studio`, `OpenJDK 21`, `Android SDK 35/36`, `Build-Tools`, `Platform-Tools`, `Emulator`, `udev`-правила, `kvm`).
- [x] Спроектировано и реализовано нативное Android-приложение на Kotlin + Jetpack Compose + Material 3 (`com.ptd450vp.labelprinter`).
- [x] Реализован растровый протокол Brother P-touch Raster (`RasterProtocol.kt`, `PackBitsEncoder.kt`, `PrinterStatus.kt`) с юнит-тестами.
- [x] Реализован USB Host (USB OTG) транспорт (`UsbPrinterTransport.kt`) + `device_filter.xml` (`VID 0x04F9`, `PID 0x2073`) и встроенный симулятор принтера (`MockPrinterTransport`).
- [x] Реализован редактор этикеток: однострочный/многострочный текст, шрифты/размеры/автоподбор, QR-коды (UTF-8), штрихкоды (`Code 128`, `EAN-13`, `Code 39`, `Data Matrix`), картинки из галереи с бинаризацией и дизерингом Флойда–Стейнберга.
- [x] Реализована система шаблонов: 6 встроенных + сохранение/удаление пользовательских шаблонов в JSON.
- [x] Подключён реальный принтер **Brother PT-D450VP** по USB к ПК, подтверждены `VID:PID 04f9:2073`, интерфейс `Class 7`, эндпоинты `EP 2 OUT / EP 1 IN` и реальный 32-байтный статус (`modelCode = 0x69`, 12 мм белая TZe).
- [x] Настроен Git-репозиторий `kprklg/android-brother-pt-d450vp`, `git-crypt`, `group_vars/all/secrets.yml`, зашифрованный экспорт сессий `session/*.json`, полная документация и релиз `v0.1.0`.
- [x] Сняты и опубликованы скриншоты интерфейса (`docs/screenshots/`) на эмуляторе Android 15 (Pixel 6), исправлены светлые иконки статус-бара (`enableEdgeToEdge`).
- [x] Правила работы зафиксированы в `AGENTS.md` (читается OpenCode автоматически), README актуализирован по версиям.
